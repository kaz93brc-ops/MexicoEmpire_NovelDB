# Hamnett Juárez Source Trail Index

## 1. Purpose

This file organizes Brian R. Hamnett, *Juárez* as a source-discovery route into Juárez-side and republican-side primary or quasi-primary evidence. It is not a Fact Card set, not a Timeline set, and not a storage location for Hamnett's text or notes.

Main purpose:

- Correct the Maximilian / Habsburg / French / loyal-witness pull in the Shawcross-derived DB.
- Identify routes into Juárez, republican government, Liberal Reform, anti-French resistance, trial, execution decision, and postwar memory sources.
- Connect `RSG_MEXEMP_0001-0022` to concrete Hamnett abbreviations and next-reading targets.
- Prepare cross-check routes against Shawcross-side `NSI_SHAWCROSS_####`, `SRM_SHAWCROSS_####`, and `NRC_SHAWCROSS_####`.
- Keep historical verification separate from novel-scene use.

Hamnett is treated here as a guide to source trails. Hamnett's narrative should not be fixed as the final evidence for Fact Cards without checking the cited primary, quasi-primary, archive, press, or official documents directly.
