## 2. Operating Rules

- 市販書籍本文、スクリーンショット内文章、NOTES本文の全文保存、全文文字起こし、長文引用は禁止。
- 本文ページは `secondary_summary` とし、既存 Capture / Fact / Timeline のID照合を中心に扱う。
- NOTESページは本文Fact化せず、出典探索インデックス `source_index` として扱う。
- ACKNOWLEDGMENTSは歴史本文ではないため `excluded` とし、原則としてFact / Timeline化しない。
- ID範囲は、既存ファイル実在で確認できたものを優先する。Capture本文にのみ記載がある範囲、または隣接IDからの推定は、必ず推定または未確認と明記する。
- 欠番・重複・不整合疑いはこの工程表に記録し、本格監査は次工程の CAP / FACT / TIME ID欠番・重複監査へ引き継ぐ。
