# Entity Card Consolidation Audit

## 1. Purpose

This file is a management document for inventorying, consolidation review, and reinforcement planning for existing Event / Place / Org / Theme cards in `MexicoEmpire_NovelDB`.

This pass does not edit, delete, rename, merge, or substantially expand the Event / Place / Org / Theme card bodies. It also does not create new Event, Place, Org, Theme, Fact, or Timeline cards.

Hamnett *Juárez* body text and notes have not been ingested. Republican-side reinforcement is therefore recorded only as a follow-up candidate, with `manual_review_needed` retained. HJI and RSG are treated here as source-trail and source-gap planning documents, not as proof that the Hamnett text or the underlying documents have been read.

The purpose is to compare existing entity cards against `CTL_MEXEMP_0001-0032`, `CDL_MEXEMP_0001-0016`, and `NCD_MEXEMP_0001-0031`, identify overlap and missing entity candidates, and set priorities for later safe card updates.

Maximilian-centered narrative risk remains high in many rows because the current database is primarily Shawcross-derived. Juárez should not be fixed as either a simple executioner or a flawless heroic figure. Carlota should not be reduced to a tragic heroine only. Basch / Blasio / Felix Salm-Salm / Agnes Salm-Salm testimony clusters remain useful for novel texture but require verification. Newspapers should be treated as public opinion / propaganda / rumor sources unless issue, date, political position, and article-level context are verified.
