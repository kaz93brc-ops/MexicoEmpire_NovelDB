# 02_Fact_Cards

Fact Cardは「1カード1主張」です。

カードには、主張、根拠、出典位置、証拠分類、信頼度、関連リンク、創作利用メモを分けて記録します。史実と創作用推測を同じ欄に混ぜないでください。
