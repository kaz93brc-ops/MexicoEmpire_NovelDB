# 01_Sources

出典単位のSource Noteを管理します。

推奨配置:

- `Source_Notes/`: 書籍、論文、史料集、アーカイブ資料ごとのSource Note
- `Captures/`: 出典位置を確認した整理済みCapture Note
- `Primary/`: 一次史料に関する管理ノート
- `Secondary/`: 研究書、論文、解説書に関する管理ノート

本文そのものではなく、出典情報、短い要約、利用範囲、確認したい論点を記録します。
