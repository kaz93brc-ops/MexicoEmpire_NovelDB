# REL_MEXEMP_0005 Carlota - Napoleon III

## Summary / 関係性の大意

CarlotaとNapoleon IIIの関係は、帝政計画への信頼、対仏依存、援助要請、裏切られた期待として読める材料がある。CarlotaはNapoleon IIIをメキシコ再生の大事業を遂行できる後援者と見ていたとShawcrossは描くが、その評価は著者解釈であり、Carlota本人の書簡・外交文書での補強が必要である。1866年の渡欧・交渉は、Carlotaを単なる配偶者ではなく外交的行為者として扱う入口になる。

## Evidence-Based Points / 根拠付きポイント

- Interpretation / ShawcrossはCarlotaがNapoleon IIIを大きく信頼していたと描く。根拠: [[FACT_MEXEMP_0642]]. confidence: medium-low. note: author interpretation.
- Fact / Primary testimony: Carlotaは疑念があってもNapoleon IIIの好意を信じられるはずだとMaximilianを励ました。根拠: [[FACT_MEXEMP_1268]]. confidence: medium. note: 原書簡の文脈確認が必要。
- Inference / MaximilianとCarlotaはNapoleon IIIが自分たちを見捨てないと確信していたと叙述される。根拠: [[FACT_MEXEMP_1267]]. confidence: low-to-medium. note: 心理描写として扱う。
- Fact / 1864年、Maximilianの療養中にCarlotaがNapoleon IIIへの礼状を代筆した。根拠: [[FACT_MEXEMP_0820]]. confidence: medium.
- Fact / 1865年、Dano対応でCarlotaはフランス外交官に楽観的印象を与えた。根拠: [[FACT_MEXEMP_1263]], [[FACT_MEXEMP_1264]], [[FACT_MEXEMP_1265]]. confidence: medium. note: Dano reportの原文要確認。
- Fact / 1866年8月、CarlotaのFrance到着直前にMaximilianは、Napoleon IIIからtroops残留・財政支援・Bazaine更迭を交渉する好機だと書いた。根拠: [[TIME_MEXEMP_0238]]. confidence: medium.
- Fact / 1866年8月29日、Napoleon IIIは追加資金・追加兵力提供は不可能と通告した。根拠: [[TIME_MEXEMP_0275]]. confidence: medium.
- Fact / 1866年9月14日、BlasioがCarlotaの異変、書簡改竄への疑念、Napoleon IIIへの恐怖を察知したとされる。根拠: [[TIME_MEXEMP_0249]]. confidence: low-to-medium. note: Blasio証言として扱う。

## Tensions / 緊張・対立・不一致

- Carlota側の信頼・期待と、Napoleon III側の国内政治・財政・撤兵判断が乖離する。根拠: [[FACT_MEXEMP_0642]], [[FACT_MEXEMP_1268]], [[FACT_MEXEMP_1406]], [[FACT_MEXEMP_1429]], [[TIME_MEXEMP_0275]].
- CarlotaはNapoleon IIIを必要な後援者として扱うが、彼への依存は帝国自立の弱さを露出させる。根拠: [[FACT_MEXEMP_0820]], [[TIME_MEXEMP_0238]].
- BlasioなどのCarlota異変・恐怖に関する証言は scene-rich だが、回想録・近接証言の主観を含む。根拠: [[TIME_MEXEMP_0249]], [[SRM_SHAWCROSS_0038]].

## Cooperation / 協力・利害一致

- CarlotaはNapoleon IIIとの関係を、帝国継続に必要な外交的支援路として使おうとした。根拠: [[FACT_MEXEMP_0820]], [[FACT_MEXEMP_1268]], [[TIME_MEXEMP_0238]].
- Napoleon IIIは初期の帝政計画でMaximilian-Carlota夫妻を支える構図を作ったが、後期には追加支援を拒む側へ移る。根拠: [[FACT_MEXEMP_0205]], [[FACT_MEXEMP_0613]], [[TIME_MEXEMP_0275]].

## Change Over Time / 時期による変化

- 1861-1864: Napoleon IIIは帝政計画を動かす後援者として認識される。根拠: [[FACT_MEXEMP_0205]], [[FACT_MEXEMP_0238]], [[FACT_MEXEMP_0642]].
- 1864: Carlotaは礼状代筆などで対仏実務に関与する。根拠: [[FACT_MEXEMP_0820]].
- 1865: Dano対応で対仏印象管理が必要になる。根拠: [[FACT_MEXEMP_1263]], [[FACT_MEXEMP_1264]], [[FACT_MEXEMP_1265]].
- 1866: Carlota渡欧と追加支援拒否で、信頼関係は崩壊局面に入る。根拠: [[TIME_MEXEMP_0238]], [[TIME_MEXEMP_0249]], [[TIME_MEXEMP_0275]].

## Interpretive Cautions / 解釈上の注意

- CarlotaのNapoleon III信頼を「無批判」と断定しない。これはShawcrossの評価を含む。
- Carlotaの渡欧を、病状・悲劇だけでなく外交任務としても扱う。
- Blasioや宮廷証言からCarlotaの心理を直接断定しない。
- French official records、Belgian/Habsburg correspondence、Carlota書簡で補強する。

## Novel Use Materials / 小説利用の材料

- Carlotaは、夫の代理・後援者への交渉者・帝国継続を背負う外交 actor として描ける。
- Napoleon IIIへの信頼が、希望、政治判断、依存、裏切られた期待のどれとして読めるかを場面ごとに分けられる。
- Saint-Cloud / France到着 / Blasio視点は、政治交渉と心理崩壊を混ぜずに交互配置できる。

## Open Questions / 要確認

- CarlotaからNapoleon IIIへの書簡・礼状の原文。
- Dano reportの原文・日付・宛先。
- CarlotaのFrance滞在中の面会記録、Saint-Cloud audienceの公的記録。
- Blasio証言とCarlota本人書簡・Habsburg/Belgian recordsの照合。
