# REL_MEXEMP_0009 Carlota - imperial court / imperial project

## Summary / 関係性の大意

Carlotaは、Maximilianの配偶者としてだけでなく、帝国計画の実務・外交・宮廷演出を支える人物として読める材料がある。宮廷内で孤立していたか、実務的支柱だったかは二者択一にせず、代筆、接待、巡幸、宮廷社交、渡欧交渉、変調を時期ごとに分けて扱う必要がある。

## Evidence-Based Points / 根拠付きポイント

- Maximilianの療養中、CarlotaはNapoleon IIIへの礼状を作成し、Maximilianが署名したとされる。
  - 根拠: [[FACT_MEXEMP_0820]]
  - confidence: medium
  - category: Fact / Primary testimony
- Maximilianの宮廷作法書は細かな階層秩序を規定した。
  - 根拠: [[FACT_MEXEMP_0833]]
  - confidence: medium
  - category: Fact
- MaximilianはDanoを好印象で迎える必要をCarlotaに伝え、CarlotaはDanoを接待して楽観的印象を与えた。
  - 根拠: [[FACT_MEXEMP_1263]], [[FACT_MEXEMP_1264]]
  - confidence: medium
  - category: Fact / Primary testimony
- DanoはMaximilian夫妻を批判に敏感で、助言を受け入れるには慎重な言い方が必要な人物たちと見た。
  - 根拠: [[FACT_MEXEMP_1265]]
  - confidence: medium
  - category: Fact / Primary testimony
- CarlotaはMaximilianの代行としてYucatánへ向かい、大きな随行団を伴った。
  - 根拠: [[TIME_MEXEMP_0201]]
  - confidence: medium
  - category: Fact
- Cuernavacaでは、MaximilianとCarlotaが縮小されたinformalな宮廷を保ったとされる。
  - 根拠: [[FACT_MEXEMP_1441]], [[FACT_MEXEMP_1445]]
  - confidence: medium
  - category: Fact / Primary testimony
- 1866年渡欧前、MaximilianはCarlotaにFrench troops残留、財政支援、Bazaine更迭交渉への期待を書き送った。
  - 根拠: [[TIME_MEXEMP_0238]]
  - confidence: medium
  - category: Fact / Primary testimony

## Tensions / 緊張・対立・不一致

- Carlotaの実務性は、帝国計画の支柱としても、破綻寸前の計画への過剰な投入としても読める。
- 宮廷儀礼・序列の整備は統治の演出である一方、フランス側外交官には実行力不足が問題視された。根拠: [[FACT_MEXEMP_1266]], [[FACT_MEXEMP_1273]].
- Blasioが見たCarlotaの異変・Napoleon IIIへの恐怖は、証言性の確認なしに心理確定へ使わない。根拠: [[TIME_MEXEMP_0249]].

## Cooperation / 協力・利害一致

- Carlotaは、礼状代筆、外交官接待、巡幸、渡欧交渉などでMaximilianの政治的実務を補完した。
- 宮廷は帝国の正統性を可視化する装置であり、Carlotaはその顔として機能した可能性がある。

## Change Over Time / 時期による変化

- 1864: Miramar受諾直後、CarlotaはNapoleon IIIへの礼状代筆で帝政受諾の外交礼法に関わる。根拠: [[FACT_MEXEMP_0820]].
- 1865: Dano接待、Yucatán巡幸、Cuernavaca宮廷など、Carlotaの実務的役割が見える。根拠: [[FACT_MEXEMP_1264]], [[TIME_MEXEMP_0201]], [[FACT_MEXEMP_1441]].
- 1866: 渡欧交渉で、帝国計画維持の外交的賭けを担う。根拠: [[TIME_MEXEMP_0238]], [[TIME_MEXEMP_0249]].
- 1867: Carlota不在後の帝政は、宮廷計画より軍事・法的崩壊へ移る。

## Interpretive Cautions / 解釈上の注意

- Carlotaを「孤立した悲劇の皇后」または「帝政を支配した人物」に固定しない。
- 宮廷の華やかさと統治能力を混同しない。
- Dano、Blasio、宮廷関係者の証言は近接性がある一方、自己弁護・回想・印象評価の性格を持つ。

## Novel Use Materials / 小説利用の材料

- Carlotaは、宮廷の顔、外交の補助線、計画の実務者、危機の使者として複数の層で使える。
- Dano接待やYucatán巡幸は、帝国がまだ機能しているように見せる場面と、内実の不安を並置できる。
- Cuernavacaのinformal courtは、親密さと現実逃避の両方を示す空間にできる。

## Open Questions / 要確認

- Carlota書簡とMaximilian書簡の原文・編集方針。
- Yucatán巡幸の現地反応、随行団、政策目的。
- Blasio証言の範囲と、Carlotaの病状・恐怖に関する他史料照合。
