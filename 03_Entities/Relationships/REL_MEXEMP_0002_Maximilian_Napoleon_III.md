# REL_MEXEMP_0002 Maximilian - Napoleon III

## Summary / 関係性の大意

MaximilianとNapoleon IIIの関係は、後援者と被後援者、帝政計画の設計者と担い手、外交的保証をめぐる交渉相手、撤兵期の責任転嫁を含む関係として整理できる。DB上では、Napoleon III側の曖昧な支援示唆、Maximilianの正統性条件、British supportや米国抑止をめぐる誤認・楽観、1865-1866年のフランス側信頼低下と撤兵決定が段階的に見える。

## Evidence-Based Points / 根拠付きポイント

- Fact / Napoleon IIIはMetternich経由でMaximilian候補支持を非公式に示した。根拠: [[FACT_MEXEMP_0205]], [[FACT_MEXEMP_0207]]. confidence: medium. note: 外交文書未確認。
- Fact / FranceはBritainとSpainの支持も得られると示唆したが、公式性・実現性は不確実。根拠: [[FACT_MEXEMP_0206]]. confidence: low. note: diplomatic promise / 要確認。
- Fact / MaximilianはNapoleon III宛書簡で、メキシコ国民の明確な意思表示を受諾条件とした。根拠: [[FACT_MEXEMP_0258]]. confidence: medium. note: 実際の民意確認とは分ける。
- Interpretation / British support確保済みというNapoleon III側説明は虚偽だったとShawcrossは整理する。根拠: [[FACT_MEXEMP_0259]], [[FACT_MEXEMP_0260]]. confidence: medium-low. note: British government側史料で要確認。
- Fact / Primary testimony: Napoleon IIIは、選挙・議会承認を後回しにし、まず秩序を確立すべきだとMaximilianに説いた。根拠: [[FACT_MEXEMP_0644]]. confidence: medium. note: political inducementとして読む。
- Fact / Primary testimony: Maximilianは、フランス軍だけでUnited Statesを抑止できるとNapoleon IIIに書き、Napoleon IIIもその判断を後押しした。根拠: [[FACT_MEXEMP_0612]], [[FACT_MEXEMP_0613]]. confidence: medium. note: 実際の米国政策とは分ける。
- Inference / MaximilianはNapoleon IIIへの完全依存を避けようとしてFranz Josephにも支援を求めた。根拠: [[FACT_MEXEMP_0617]]. confidence: medium.
- Interpretation / 1865年時点でNapoleon IIIはMaximilianへの信頼を急速に失っていたと整理される。根拠: [[FACT_MEXEMP_1272]], [[FACT_MEXEMP_1274]]. confidence: medium-low. note: French official papersで補強が必要。
- Fact / 1866年1月22日、Napoleon IIIはメキシコ遠征終結と兵の召還時期調整を公的に述べた。根拠: [[TIME_MEXEMP_0215]], [[FACT_MEXEMP_1428]], [[FACT_MEXEMP_1430]]. confidence: medium.
- Interpretation / MaximilianはNapoleon IIIが政治的に自分を見捨てたことをまだ知らなかったとShawcrossは描く。根拠: [[FACT_MEXEMP_1432]]. confidence: low-to-medium. note: 情報到達時期と内面判断は要確認。
- Fact / 1866年8月29日、Napoleon IIIはMaximilian宛書簡で追加資金・追加兵力は不可能と通告した。根拠: [[TIME_MEXEMP_0275]]. confidence: medium.

## Tensions / 緊張・対立・不一致

- Maximilianは正統性や民意確認を求める一方、Napoleon IIIは秩序確立を先に置くよう説いた。根拠: [[FACT_MEXEMP_0258]], [[FACT_MEXEMP_0644]].
- MaximilianはFrench supportに依存しながら、その完全依存を避けようとした。根拠: [[FACT_MEXEMP_0617]], [[FACT_MEXEMP_0823]].
- Napoleon IIIはメキシコ政策を議会・国内政治の批判にさらされ、追加資金・兵力負担を抑える方向へ動いた。根拠: [[FACT_MEXEMP_1405]], [[FACT_MEXEMP_1406]], [[FACT_MEXEMP_1412]], [[TIME_MEXEMP_0215]].
- 公式説明では帝政安定が語られたが、実際には財政・軍事・米国圧力が強まっていた。根拠: [[FACT_MEXEMP_1411]], [[FACT_MEXEMP_1429]], [[FACT_MEXEMP_1546]], [[FACT_MEXEMP_1551]].

## Cooperation / 協力・利害一致

- Napoleon IIIにとってMaximilianはメキシコ君主制計画の不可欠な候補になったとShawcrossは整理する。根拠: [[FACT_MEXEMP_0238]]. note: author interpretation.
- 1864年の帝位受諾・Treaty of Miramar・借款・義勇部隊計画は、両者の利害が一時的に結びついた制度的結節点。根拠: [[TIME_MEXEMP_0136]], [[TIME_MEXEMP_0137]], [[FACT_MEXEMP_0811]].
- 1864-1865年には、対米抑止やFrench troops残留をめぐり、相互に楽観的判断を支え合う材料がある。根拠: [[FACT_MEXEMP_0612]], [[FACT_MEXEMP_0613]], [[FACT_MEXEMP_1267]].

## Change Over Time / 時期による変化

- 1856: MaximilianとNapoleon IIIの初期接触には評価の揺れがある。根拠: [[FACT_MEXEMP_0077]], [[FACT_MEXEMP_0078]], [[FACT_MEXEMP_0084]].
- 1861-1862: 非公式支援示唆、候補選定、正統性条件、British support問題が関係の基礎になる。根拠: [[FACT_MEXEMP_0205]], [[FACT_MEXEMP_0258]], [[FACT_MEXEMP_0260]].
- 1864: Miramarと渡航で、French supportは帝政の外的支柱として可視化される。根拠: [[TIME_MEXEMP_0136]], [[FACT_MEXEMP_0823]].
- 1865: Dano報告、財政問題、Napoleon III側の信頼低下が強まる。根拠: [[FACT_MEXEMP_1265]], [[FACT_MEXEMP_1266]], [[FACT_MEXEMP_1270]], [[FACT_MEXEMP_1272]], [[FACT_MEXEMP_1274]].
- 1866: Napoleon IIIの公的撤兵表明、Carlota渡欧、追加支援拒否で関係は破綻方向へ進む。根拠: [[TIME_MEXEMP_0215]], [[TIME_MEXEMP_0238]], [[TIME_MEXEMP_0275]], [[TIME_MEXEMP_0282]].
- 1867: French withdrawal後、Maximilianの軍事的自立の脆弱さが露出する。根拠: [[FACT_MEXEMP_2035]], [[FACT_MEXEMP_2036]], [[FACT_MEXEMP_2037]].

## Interpretive Cautions / 解釈上の注意

- Napoleon IIIを単純な悪役または唯一の原因にしない。国内政治、議会批判、米国圧力、財政負担、French military commandの事情を分ける。
- 「利用と放棄」は小説上強い構図だが、各段階で何が約束され、何が曖昧だったかをAAE / 400AP / FO / U.S. documentsで確認する。
- Shawcrossの「deserted」「false」系の叙述は強い。カードではInterpretationとして扱い、外交文書で補強する。

## Novel Use Materials / 小説利用の材料

- 1861-1862年は、曖昧な保証と期待の積み上げとして描ける。
- 1864年は、華やかな制度的結婚ではなく、借款・軍事・民意確認の未解決を抱えた契約として扱える。
- 1865-1866年は、Parisの議会・財政・世論とMexicoの宮廷楽観を交互に配置できる。
- MaximilianにとってNapoleon IIIは支援者であると同時に、自立を妨げる依存先として描く余地がある。

## Open Questions / 要確認

- British supportに関する実際の英仏交渉とMaximilianへの説明。
- Treaty of Miramarの条項、借款、兵力支援の正確な法的関係。
- 1866年1月22日演説の原文とCorps législatifでの反応。
- 1866年8月29日書簡の全文とMaximilian到達日。
