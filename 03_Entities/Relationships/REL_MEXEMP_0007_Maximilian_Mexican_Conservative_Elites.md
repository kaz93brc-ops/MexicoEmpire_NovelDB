# REL_MEXEMP_0007 Maximilian - Mexican conservative elites

## Summary / 関係性の大意

Maximilianとメキシコ保守派エリートの関係は、帝政成立に不可欠な支持基盤でありながら、Maximilianの自由主義的自己像、教会財産・和解政策、Juaristas取り込み方針によって早期に緊張を抱えた関係として読める。保守派が一枚岩でMaximilianを支持した、または一斉に失望した、と断定せず、Almonte、Gutiérrez de Estrada、Miramón、Márquez、Mejía、教会勢力を分けて見る必要がある。

  - confidence: medium
  - category: Fact

  - 根拠: [[FACT_MEXEMP_0722]]
  - confidence: medium

## Tensions / 緊張・対立・不一致

- 保守派は帝政の現地正統性と軍事的顔を提供したが、Maximilianの自由主義的政策は保守派・教会勢力の期待とずれた。
- 保守派軍人は帝国に戦闘力を与えた一方、自由派取り込みの妨げにもなりうる。
- Gutiérrez de EstradaやAlmonteのような亡命・保守派情報が、メキシコ世論全体を代表したとは限らない。根拠: [[FACT_MEXEMP_0446]].

## Cooperation / 協力・利害一致

- 保守派は帝政構想の初期政治・軍事・儀礼基盤を作った。
- Maximilian側は保守派の支持を完全には断ち切れず、保守派側も共和国に対抗するため帝政に接続した。
- 保守派軍人の存在は、French interventionを単なる外国軍事占領ではなく、メキシコ人協力者を伴う政治軍事事業として見せる機能を持った。

## Change Over Time / 時期による変化

- 1861-1863: Almonteらがフランス軍周辺で保守派を集め、Junta/Regencyへ接続する。根拠: [[FACT_MEXEMP_0355]], [[FACT_MEXEMP_0554]], [[FACT_MEXEMP_0557]].
- 1864: Maximilian受諾後、保守派支援と自由主義的綱領の矛盾が帝政初期政策に入る。根拠: [[FACT_MEXEMP_0922]], [[FACT_MEXEMP_0928]].
- 1865: 教会問題、Meglia、軍事・財政問題により保守派期待との緊張が強まる。根拠: [[FACT_MEXEMP_1137]], [[FACT_MEXEMP_1277]].
- 1866: フランス撤退が近づく中、保守派軍人・帝国軍への依存が再び増す。
- 1867: QuerétaroではMiramón、Márquez、Mejíaなど保守派軍人が最終局面の帝政側軍事判断に深く関わる。根拠: [[FACT_MEXEMP_2117]], [[FACT_MEXEMP_2164]].

## Interpretive Cautions / 解釈上の注意

- 「メキシコ保守派」を単一人格のように扱わない。亡命政治家、教会勢力、地方軍人、Regency関係者で利害が違う。
- Shawcross由来のMaximilian/Carlota内面解釈は、保守派側一次資料で補強する。
- 保守派の失望時期は一律ではなく、政策ごと、人物ごとに分ける。

## Novel Use Materials / 小説利用の材料

- 帝政成立に必要だった味方が、同時にMaximilianの自由主義的構想を狭める構図にできる。
- Almonteは政治工作、Miramón/Márquez/Mejíaは軍事的現地性、教会勢力は思想・制度上の圧力として分けて使える。
- 保守派の支持と失望を、一回の裏切りではなく、期待違いの蓄積として描ける。

## Open Questions / 要確認

- 保守派各人物の書簡・回想録・新聞で、Maximilianへの評価変化を確認する。
- 教会財産・教会政策への保守派反応を、Catholic Church側史料で補強する。
- Almonte、Gutiérrez de Estrada、Labastida、Miramón、Márquez、Mejíaを同じ保守派枠で処理してよい範囲を切り分ける。
