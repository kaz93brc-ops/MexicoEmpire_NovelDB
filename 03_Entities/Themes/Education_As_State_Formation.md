# Education As State Formation

## Definition

初等教育を通じて、市民的義務を理解する共和国の個人を形成しようとする国家形成構想。

## Hamnett 1994 p.36-37 Notes

Hamnettは、Juárezの長期戦略を、法人団体・民族的共同体・親族・庇護関係中心の社会から、市民的義務を担う共和国社会への転換として整理する。

## Creative Use

教育政策を単純な解放政策ではなく、社会を作り替える統合主義として描く材料。Maximilianの上からの改革構想との比較軸になる。
