# Juarez first state governorship

## Definition

Entry note for Juarez first state governorship. Keep historical evidence, interpretation, and creative use separate.

## Hamnett 1994 p.34-35 Notes

Hamnett p.34-35では、1847年10月29日の州議会指名、暫定知事としての自己正当化、1848年8月12日の憲法上の正式就任が整理される。知事就任は理念面では高潔な原則を掲げつつ、手続上は不規則だったと評価される。

## Hamnett 1994 p.38-39 Notes

Hamnett p.38-39では、Juárezが不安定なOaxaca州知事任期を全うできた一因として、National Guard再建、Commander-General職への警戒、Castellanosの忠誠など、文民権威を補強する軍事力が整理される。
