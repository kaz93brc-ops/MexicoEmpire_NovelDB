# State capacity

## Historical Role

Oaxaca州政府が徴税・治安・軍事力・地方人事を通じて実効支配を確保できるかを扱う主題。

## Creative Use

Isthmus危機を、地方政治・州統治・中央政治・軍事力の接点として描くための接続先。
