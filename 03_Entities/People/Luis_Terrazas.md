# Luis Terrazas

## Overview

Chihuahuaの地方有力者。Hamnettは、TerrazasをLiberal / Conservative、federal / central の単純分類では把握できない地方エリートの例として扱う。French Intervention期にはJuárezの保護者となるが、初期から一貫したjuaristaだったわけではなく、態度決定には時間を要したとされる。
