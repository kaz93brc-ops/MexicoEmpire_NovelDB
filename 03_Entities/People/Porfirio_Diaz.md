# Porfirio Díaz

## Basic Role / 基本的役割

共和派軍人。OaxacaとArmy of the Eastを軸に、帝政への南・東方面からの軍事圧力を担う。

## Character Evidence / 人物像検討材料

### 行動傾向として読める材料

- Fact / Puebla後に捕虜状態から逃れ、Oaxacaで共和派勢力を結集したとされる。根拠: [[FACT_MEXEMP_1280]].
- Fact / 1865年Oaxaca包囲では降伏し、約4,000人とともに捕虜となった。根拠: [[FACT_MEXEMP_1281]], [[FACT_MEXEMP_1284]].
