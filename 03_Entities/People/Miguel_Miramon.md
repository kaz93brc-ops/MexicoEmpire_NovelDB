# Miguel Miramón

## Basic Role / 基本的役割

メキシコ保守派軍人。保守派側では大統領と見なされた人物で、帝政最終局面ではMaximilian側に加わる。

## Character Evidence / 人物像検討材料

### 行動傾向として読める材料

- Fact / 保守派支持者からはメキシコ大統領と見なされたが、反対派は承認していなかった。根拠: [[FACT_MEXEMP_0002]].
- Fact / Napoleon IIIからMaximilian擁立協力を求められたが、実効的な君主派政党がない趣旨で拒否したとされる。根拠: [[FACT_MEXEMP_0278]], [[FACT_MEXEMP_0279]], [[FACT_MEXEMP_0280]]. note: 発言原典要確認。
- Fact / 1863年7月にメキシコへ戻り、現地兵部隊を率いた。根拠: [[FACT_MEXEMP_0720]], [[FACT_MEXEMP_0721]].

### 政治的判断・危機対応の傾向

- Inference / 初期にはMaximilian擁立への懐疑を示す材料があり、後には帝政軍事側に加わるため、保守派内の判断変化を示す人物として使える。
- Fact / 1866年11月にMiramón夫妻がVeracruzへ到着した。根拠: [[FACT_MEXEMP_1920]].
- Fact / Escobedoとの戦闘でMiramón軍は壊滅的敗北を喫した。根拠: [[FACT_MEXEMP_2106]], [[FACT_MEXEMP_2108]].

### 主要人物との関係性

- Napoleon III: 初期工作の対象。根拠: [[FACT_MEXEMP_0278]], [[FACT_MEXEMP_0279]].
