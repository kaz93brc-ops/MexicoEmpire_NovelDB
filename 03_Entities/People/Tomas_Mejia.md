# Tomás Mejía

## Basic Role / 基本的役割

Sierra Gordaに基盤を持つOtomí系保守派軍人。地域的・先住民保守派の材料として重要で、Maximilian、Miramónとともに最終局面に関わる。

## Character Evidence / 人物像検討材料

### 行動傾向として読める材料

- Fact / Sierra Gorda出身のOtomíとして描かれる。根拠: [[FACT_MEXEMP_0003]], [[FACT_MEXEMP_0702]].
- Fact / 米墨戦争で騎兵将校として従軍し、内戦期には保守派として戦った。根拠: [[FACT_MEXEMP_0703]], [[FACT_MEXEMP_0704]].
- Fact / 1861年以後、山岳地帯で抵抗を続け、政府軍を撃退したとされる。根拠: [[FACT_MEXEMP_0705]], [[FACT_MEXEMP_0706]].

### 政治的判断・危機対応の傾向

- Fact / 帝国への忠誠を最近表明した地方軍指揮官として描かれる。根拠: [[FACT_MEXEMP_0701]].
- Fact / フランス側はMejíaを高く評価し、Barailは優秀で忠実な将軍として称賛した。根拠: [[FACT_MEXEMP_0707]], [[FACT_MEXEMP_0708]]. note: French-side evaluation.
- Fact / Escobedoへの人員・資金流入の中でMatamorosを守り、後に保持できず降伏した。根拠: [[FACT_MEXEMP_1746]], [[FACT_MEXEMP_1769]].
