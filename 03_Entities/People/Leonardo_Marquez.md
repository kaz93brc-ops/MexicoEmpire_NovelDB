# Leonardo Márquez

## Basic Role / 基本的役割

メキシコ保守派軍人。Tacubayaをめぐる悪名・保守派側評価・軍事能力・帝政最終局面での助言が併存する人物。

## Character Evidence / 人物像検討材料

### 行動傾向として読める材料

- Fact / 1862年時点で42歳、米墨戦争従軍経験を持つ軍人だった。根拠: [[FACT_MEXEMP_0358]].
- Interpretation / ShawcrossはMárquezを有効な軍人、親カトリック・反自由派の人物として描く。根拠: [[FACT_MEXEMP_0366]], [[FACT_MEXEMP_0367]].
- Rumor or contested account / Tacubaya後の捕虜・負傷者・非戦闘員殺害への関与が語られる一方、保守派側には反逆者処刑・救済者としての説明がある。根拠: [[FACT_MEXEMP_0360]], [[FACT_MEXEMP_0361]], [[FACT_MEXEMP_0363]].

### 政治的判断・危機対応の傾向

- Fact / British Legationからの資金徴発でWykeから悪名高い人物と見られた。根拠: [[FACT_MEXEMP_0364]], [[FACT_MEXEMP_0365]].
- Fact / JuárezはMárquezを無法者とし賞金をかけた。根拠: [[FACT_MEXEMP_0368]].
- Fact / 1867年、MárquezはMaximilianに残存帝政軍の個人指揮とQuerétaro進軍を説いた。根拠: [[FACT_MEXEMP_2117]], [[FACT_MEXEMP_2118]].
