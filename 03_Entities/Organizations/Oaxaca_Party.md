# Oaxaca Party

## Historical Role

Hamnett p.77 uses Oaxaca party for the state-level Liberal leadership grouped around the 1857 Oaxaca elections. It is not yet clear whether this is a formal party name or Hamnett's descriptive label.

## Creative Use

Use as the local political network that makes Juárez's state-level Liberal base more concrete than a national Liberal label alone.
